# Clearbloom credits

- **Music:** original, synthesized in-app with WebAudio (`js/audio.js`). No
  audio files, no third-party music, no CC0 assets. The track is a calm
  looping night-garden pad with a gentle pentatonic melody, generated live
  in the browser — nothing to license, nothing to attribute.
- **Art:** all in-game art is drawn in code (canvas + CSS). No stock images,
  no third-party assets.
- **Fonts:** system fonts only.
